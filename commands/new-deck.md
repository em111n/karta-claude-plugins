Ты создаёшь новую презентацию в дизайн-системе **Karta**. Обязательно используй навык **karta-deck** — прочитай его `SKILL.md` и файлы в `references/` (design-tokens, primitives, section-patterns) перед вёрсткой.

Тема деки (из аргумента): **$ARGUMENTS**. Если аргумент пустой — спроси у пользователя одной строкой, про что дека и это demo или pitch.

Шаги:
1. Создай в текущей папке новую директорию со слаг-именем по теме (латиницей, через дефис).
2. Скопируй туда файлы из `template/` навыка karta-deck — это минимальная рабочая дека. Шаблон не редактируй на месте, только копию.
3. Собери секции под тему в `sections.jsx` (или `sections-a.jsx` / `-b` / `-c` по мере роста) и зарегистрируй каждую в массиве `SECTIONS`, чтобы меню их подхватило.
4. Строго соблюдай ground rules Karta: чёрный фон + acid `#ccff00` дозированно, шрифт Archivo, числа вперёд, без эмодзи, без новых цветов/шрифтов, всё внутри `<Section>`. Дизайн-систему (`colors_and_type.css`, `components.jsx`, `hero-shader.js`) НЕ трогай.
5. Бампни `?v=NN` в `index.html` после правок, подними локальное превью и покажи результат.

GitHub не нужен — это локальная работа. Когда дека готова, подскажи пользователю команду `/deck-package`, чтобы запаковать её для передачи.
